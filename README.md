# Simple_Employee_Management

A simple employee management system with session-cookie based login system built with ASP .NET MVC Core with Razor View.

---


# ✨ Features

- Session-cookie Based Authentication
- Create, Read, Update Admins
- Create, Read, Update, Delete Employees
- Microsoft SQL Database Integration
- Centralized Authentication Control

---

# 🛠️ Technology Stack

- C#
- ASP .NET Core MVC
- HTML5
- CSS3
- Booststrap
- Razor View 

---

# 🛄 NuGet Packages
